# SB24 bot

A simple Telegram text utility bot built with Python 3.12 and aiogram 3.x.

## Features

- 🔤 Sort Words — sort words alphabetically.
- 🔢 Count Text — count words, characters, characters without spaces, and lines.
- 🔀 Rearrange Letters — rearrange words or letters into a new order.

## Configuration

Create a `BOT_TOKEN` environment variable containing the token generated by BotFather.

### Local

```bash
python -m pip install -r requirements.txt
BOT_TOKEN="YOUR_BOT_TOKEN" python bot.py
```

### Docker

```bash
docker build -t sb24textbot .
docker run -e BOT_TOKEN="YOUR_BOT_TOKEN" sb24textbot
```

Never commit the bot token to the repository.
